1. Pengantar & Identitas Aplikasi

Selamat datang di Presora ("Aplikasi", "Kami", atau "Pengembang"). Presora adalah aplikasi presensi digital berbasis mobile (Flutter) yang diciptakan oleh Avrizal Rendi Prayoga untuk membantu individu, guru, pembina ekstrakurikuler, komunitas, panitia kegiatan, dan kelompok kerja dalam mengelola daftar peserta dan mencatat kehadiran secara terstruktur.

Kami berkomitmen penuh untuk menghormati dan melindungi privasi setiap pengguna. Kebijakan Privasi ini dirancang agar mudah dipahami, sesuai dengan cara kerja nyata kode aplikasi kami, dan memenuhi standar kepatuhan Google API Services User Data Policy, termasuk persyaratan Limited Use.

2. Data yang Kami Proses

Untuk mengoperasikan fungsinya, Presora memproses kategori data berikut:

A. Informasi Profil Google

Saat Anda melakukan login melalui Google Sign-In, aplikasi menerima informasi profil dasar yang diizinkan oleh akun Google Anda:

  • Alamat Email: Digunakan untuk mengidentifikasi akun Anda dan menampilkan status akun yang aktif di aplikasi.
  • Nama Tampilan (Display Name): Digunakan untuk menyapa dan menampilkan identitas pengguna di header aplikasi.
  • Foto Profil (Photo URL): Digunakan sebagai avatar visual di antarmuka aplikasi jika tersedia.

B. Data Peserta (Students / Members)

Data peserta yang dimasukkan oleh Anda ke dalam aplikasi, meliputi:

  • ID unik peserta (UUID yang dibuat oleh aplikasi).
  • Nomor Induk Siswa/Anggota (NIS/ID).
  • Nama lengkap peserta.
  • Kelas, divisi, atau nama kelompok.
  • Nomor urut pemanggilan.
  • Waktu pembuatan dan pembaruan data.

C. Catatan Presensi (Attendance Logs)

Rekaman aktivitas presensi harian, meliputi:

  • ID unik absensi.
  • Referensi ID peserta.
  • Tanggal kegiatan presensi (format YYYY-MM-DD).
  • Status kehadiran: Hadir (H), Sakit (S), Izin (I), atau Alfa (A).
  • Waktu rekaman dicatat.

D. Konfigurasi Operasional

Pengaturan hari operasional presensi (misal: Senin, Rabu) dan status validasi lembar kerja yang tersimpan dalam tab AppConfig.

3. Integrasi Akun Google & Cakupan Izin OAuth 2.0

Presora menggunakan protokol resmi Google OAuth 2.0 untuk mengautentikasi pengguna dan menghubungkan aplikasi ke Google Sheets dan Google Drive milik pengguna.

Aplikasi meminta izin spesifik berikut (Scopes):

  • email: Memverifikasi identitas pengguna dan menghubungkan preferensi pengguna pada perangkat secara lokal.
  • https://www.googleapis.com/auth/spreadsheets: Membaca, membuat sheet (Students, Attendance, AppConfig), dan menulis baris kehadiran ke Google Spreadsheet yang Anda pilih atau buat. Izin ini mutlak diperlukan untuk fungsionalitas inti aplikasi.
  • https://www.googleapis.com/auth/drive.file: Membuat dan mengelola file spreadsheet baru di Google Drive Anda jika Anda memilih fitur pembuatan spreadsheet otomatis melalui aplikasi.
  • https://www.googleapis.com/auth/drive.readonly: Membaca daftar file spreadsheet yang ada di Google Drive Anda secara read-only agar Anda dapat memilih spreadsheet mana yang ingin dihubungkan ke Presora.
Pernyataan Kepatuhan Google Limited Use:
Penggunaan dan transfer data pengguna Google yang diterima oleh Presora dari Google APIs ke aplikasi lain tunduk dan mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use. Data dari Google APIs hanya digunakan untuk menyediakan fungsionalitas presensi yang diminta langsung oleh pengguna.

4. Tujuan Penggunaan Setiap Jenis Data

Kami menggunakan data yang disebutkan di atas semata-mata untuk:

  1. Melakukan otentikasi akun Anda tanpa perlu membuat kata sandi baru.
  2. Menampilkan daftar spreadsheet Anda agar Anda dapat memilih target penyimpanan.
  3. Mencatat kehadiran peserta secara real-time dan menyimpannya langsung ke spreadsheet pilihan Anda.
  4. Menampilkan rekapitulasi kehadiran dan riwayat presensi di layar aplikasi.
  5. Mencegah duplikasi data absensi pada tanggal dan peserta yang sama.

Kami tidak pernah menggunakan data Anda untuk keperluan pemasaran, profiling iklan, analitik pihak ketiga yang invasif, atau tujuan komersial di luar fungsi inti aplikasi.

5. Cara Data Disimpan, Diproses, dan Perlindungan Token

Sesuai arsitektur kode aplikasi Presora yang dapat diverifikasi:

  • Tidak Ada Server Perantara (No Backend / No Middleman Database):
    Aplikasi Presora tidak mengoperasikan server backend atau database eksternal milik developer. Seluruh komunikasi data terjadi secara langsung (peer-to-Google) antara aplikasi mobile Anda dan endpoint resmi Google APIs (sheets.googleapis.com dan www.googleapis.com/drive) menggunakan protokol enkripsi aman HTTPS/TLS.
  • Penyimpanan Data di Google Drive Pribadi:
    Data peserta, log presensi, dan konfigurasi disimpan di dalam spreadsheet di Google Drive akun Google Anda sendiri.
  • Penyimpanan dan Perlindungan Token OAuth:
    Token autentikasi Google OAuth dikelola langsung oleh pustaka resmi Google Sign-In dan Google Play Services di perangkat Android Anda. Token akses sementara dan metadata profil lokal disimpan dalam penyimpanan internal yang terisolasi (Android SharedPreferences). Penyimpanan ini dilindungi oleh mekanisme sandbox sistem operasi Android sehingga tidak dapat diakses oleh aplikasi lain pada perangkat.
  • Token otorisasi tidak pernah dikirimkan ke server mana pun selain server otorisasi resmi Google.

6. Penjelasan Bahwa Spreadsheet Dipilih dan Dikelola oleh Pengguna

Anda memiliki kontrol mutlak atas spreadsheet yang digunakan:

  • Anda bebas memilih spreadsheet yang sudah ada di akun Google Drive Anda atau meminta aplikasi membuatkan spreadsheet baru.
  • Aplikasi hanya beroperasi pada spreadsheet yang secara eksplisit Anda pilih atau hubungkan.
  • Anda dapat membuka, mengunduh, mengedit, membagikan hak akses (share), atau menghapus spreadsheet tersebut kapan saja langsung melalui web Google Drive / Google Sheets Anda tanpa bergantung pada Presora.

7. Larangan Penjualan Data & Pengungkapan Pihak Ketiga

Kami menegaskan prinsip-prinsip mutlak berikut:

  • Data Tidak Dijual: Kami TIDAK PERNAH menjual, menyewakan, memperdagangkan, atau memonetisasi data pengguna, data peserta, rekaman kehadiran, maupun informasi profil Google kepada pihak mana pun.
  • Tidak Ada Jaringan Periklanan: Aplikasi Presora tidak memuat Software Development Kit (SDK) iklan, pelacak perilaku (behavioral trackers), atau broker data.
  • Pihak Ketiga yang Digunakan: Satu-satunya layanan pihak ketiga yang berinteraksi dengan data aplikasi adalah Google APIs (Google LLC) yang Anda otorisasi secara sadar untuk penyimpanan data spreadsheet dan autentikasi.

8. Retensi Data, Penghapusan Data, & Pembersihan Cache

Karena data Anda tersimpan di Google Drive milik Anda sendiri:

  • Retensi Data: Data peserta dan catatan presensi tersimpan selama file spreadsheet tersebut masih Anda pertahankan di Google Drive Anda.
  • Penghapusan Data: Anda dapat menghapus baris data peserta atau rekaman presensi langsung dari aplikasi, atau menghapus file spreadsheet tersebut seutuhnya dari Google Drive Anda.
  • Fitur Logout / Keluar: Ketika Anda menekan tombol "Keluar" (Logout) di aplikasi Presora, seluruh token sesi, cache email, dan metadata profil di penyimpanan lokal perangkat (SharedPreferences) akan langsung dihapus bersih secara permanen.

9. Cara Mencabut Izin Akses Akun Google (Revoking Permissions)

Anda dapat memutus atau mencabut hak akses Presora ke akun Google Anda kapan saja melalui langkah berikut:

  1. Buka halaman pengaturan keamanan akun Google Anda di: https://myaccount.google.com/permissions.
  2. Cari aplikasi Presora pada daftar "Aplikasi pihak ketiga yang memiliki akses ke akun Anda".
  3. Klik pada Presora lalu pilih tombol "Hapus Akses" (Remove Access).
  4. Setelah akses dicabut, aplikasi Presora tidak lagi dapat membaca maupun menulis ke Google Sheets Anda hingga Anda memberikan izin kembali secara sadar.
