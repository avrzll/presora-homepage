Fitur Utama

Semua yang Anda Butuhkan untuk Manajemen Presensi

Presora menghilangkan kerumitan buku absensi manual dan sistem server yang mahal. Nikmati kemudahan pencatatan dengan alur kerja yang dirancang untuk efisiensi.

Pencatatan Cepat & Intuitif

Catat status kehadiran Hadir, Sakit, Izin, atau Alfa hanya dengan satu sentuhan. Dilengkapi navigasi auto-scroll yang mempercepat presensi saat menghadapi puluhan peserta.

Pengelolaan Peserta Fleksibel

Tambah, edit, atau kelompokkan peserta berdasarkan kelas, divisi, atau nomor induk (NIS). Atur nomor urut pemanggilan sesuai kebutuhan sesi kegiatan Anda.

Konfigurasi Hari Masuk

Tentukan hari aktif presensi (misal: Senin, Rabu, atau Sabtu). Presora memvalidasi tanggal kegiatan dan mencegah kesalahan pencatatan di luar jadwal.

Integrasi Google Sheets

Data tersimpan rapi langsung di Google Spreadsheet milik Anda. Anda bebas melihat, mengedit formula, membagikan, atau membuat grafik di web Google Sheets kapan saja.

Rekapitulasi & Ekspor Excel

Pantau persentase kehadiran setiap peserta. Ekspor laporan absensi kapan pun dibutuhkan ke format spreadsheet standar tanpa terkunci pada satu format.

Bebas Vendor Lock-in

Karena data disimpan langsung di Google Drive Anda sendiri, Anda memiliki kontrol penuh 100% atas aset data Anda, bahkan jika Anda berhenti menggunakan aplikasi.

Transparansi Layanan Google

Bagaimana Presora Berinteraksi dengan Akun Google Anda

Presora tidak menggunakan database backend milik developer. Semua interaksi data terjadi secara langsung antara ponsel Anda dan layanan Google API resmi milik Anda.

Alur Kerja Data Langsung (Client-to-Google)

Pengguna melakukan otentikasi menggunakan Google Sign-In resmi. Aplikasi mengirimkan permintaan baca/tulis langsung ke Google API endpoints menggunakan protokol aman TLS/HTTPS.

Struktur Sheet Otomatis yang Digunakan:

Ketika Anda menghubungkan spreadsheet atau meminta aplikasi membuat spreadsheet baru, Presora menstrukturkan 3 tab sheet:

1. Tab "Students"
Menyimpan daftar peserta: ID unik, NIS, Nama Lengkap, Kelas/Divisi, Urutan Pemanggilan, dan Timestamp.
2. Tab "Attendance"
Menyimpan log riwayat kehadiran: ID absensi, Referensi ID Peserta, Tanggal (YYYY-MM-DD), Status (H/S/I/A), dan Waktu Input.
3. Tab "AppConfig"
Menyimpan pengaturan aplikasi: Hari operasional presensi (attendance_days) dan status validasi konfigurasi sheet.

Cakupan Izin (OAuth Scopes) yang Diminta:

Presora hanya meminta izin yang mutlak diperlukan untuk mengoperasikan fitur-fitur di atas:

Cakupan OAuth (Scope URL) Kategori Tujuan Penggunaan di Aplikasi
email Non-sensitive Mengetahui alamat email pengguna Google yang sedang aktif untuk menampilkan status koneksi pada antarmuka aplikasi.
https://www.googleapis.com/auth/spreadsheets Sensitive Membaca struktur sheet serta menambah/memperbarui baris data peserta dan rekaman absensi pada spreadsheet yang dipilih pengguna.
https://www.googleapis.com/auth/drive.file Sensitive / Recommended Membuat file spreadsheet baru di Google Drive pengguna jika pengguna memilih opsi pembuatan file baru secara otomatis melalui aplikasi.
https://www.googleapis.com/auth/drive.readonly Sensitive Menampilkan daftar nama spreadsheet yang ada di Google Drive pengguna agar pengguna dapat memilih spreadsheet yang ingin dihubungkan.
Pernyataan Kepatuhan Google API Services User Data Policy:
Penggunaan dan transfer informasi yang diterima dari Google APIs ke aplikasi lain oleh Presora tunduk dan sepenuhnya mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use. Data akun Google dan isi spreadsheet Anda tidak pernah dibagikan, dipindahtangankan, atau digunakan untuk keperluan periklanan, pemodelan kecerdasan buatan umum, maupun dijual kepada broker data pihak ketiga.
Privasi & Keamanan

Dirancang dengan Prinsip Privasi Pertama (Local-First)

Kami meyakini bahwa data absensi anggota atau siswa Anda adalah milik organisasi Anda seutuhnya, bukan komoditas kami.

Tanpa Server Perantara

Developer Presora tidak mengoperasikan database cloud perantara. Permintaan data langsung dialirkan dari ponsel Anda ke server resmi Google Cloud Platform menggunakan enkripsi standar HTTPS.

Penyimpanan Token Lokal

Sesi login dikelola oleh sistem Android dan disimpan di penyimpanan aplikasi lokal (SharedPreferences). Token tidak pernah dikirimkan ke server eksternal selain endpoint otorisasi resmi Google.

Pencabutan Izin Kapan Saja

Anda memegang kendali penuh. Anda dapat memutuskan tautan spreadsheet langsung dari aplikasi, atau mencabut izin aplikasi Presora secara permanen melalui pengaturan Keamanan Akun Google Anda.
